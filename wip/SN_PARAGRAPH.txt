
NEW TOOLCHAIN (read this before anything else): the melalawi/ragewars-decomp project (CC0, same game, same ROM) builds EVERYTHING with one setup: the pmret gcc 2.8.1 cc1 `-O2 -mgas -mcpu=VR4300 -mhard-float -mgp32 -mfp64 -mno-fix4300`, whose output is normalised by `n64link asn64` (the SN64 assembler's behaviour) and then assembled with GNU as. That is the real original toolchain; our older decompals-gcc + tools\gas_compat.py emulation is an approximation (many register-pin / empty-asm / permuter hacks in the earlier findings partly compensate for it). It is installed (~/sn in WSL) and wired into the checker: add the token `@SN` to a chk list line (e.g. `wip/c/foo.c func_00245840 0x46440 @SN`, optionally with `-fno-builtin`; use `@SN272` for the low code region below ROM 0x2000, which that project builds with gcc 2.7.2) and the function is compiled with it. A natural source form that matches under @SN is better than a pin-hack under the old flags, so for every target try @SN FIRST with the plain m2c/hand draft, then fall back to the old flags. Their matched sources are in D:\Projects\ext\ragewars-decomp\src (files func_80XXXXXX_de.c, named by the German-version address; use D:\Projects\ext\ragewars-decomp\versions\us-rev1\symbol_addrs.txt to map their names to our addresses): neighbouring functions of your targets are already matched there, so grep them for the idioms (struct shapes, macro helpers such as `({ })` blocks, loop forms) their author used. `python tools\their_diff.py` lists what they match that we do not (already ported). Their headers (include\their\) define types; in sn mode the checker adds -I include/their, so `#include "types.h"` etc. work.
When a function matches under @SN, put the token in the results.txt flags field (`@SN`, plus `-fno-builtin` if used). The lead integrates sn results with `mode=sn`, so the C file must be self-contained for the sn pipeline (preprocessed with `cpp -P -undef -nostdinc -D_LANGUAGE_C -DF3DEX_GBI_2 -D__GNUC__=2 -D__UNBAKE_STDARG_GCC -DVERSION_US_REV1 -I include -I include/their`; no system headers). A function that matches only under the old flags is still welcome (note which).
